# Miuix 界面迁移

前端沿用版本目录固定的 Miuix `0.9.4`。导航仍由 `miuix-nav` 管理；此次迁移不改变路由、规则执行、数据库结构、订阅更新或权限授权流程。

- `AppTheme` 统一提供 Miuix 浅色、深色、跟随系统及动态配色；与启动页、全局窗口和悬浮层使用同一套视觉语言。
- 首页以服务状态为主，应用和订阅统计为次；设置、数据概览和快捷入口使用带读屏标题的 Miuix 卡片分组。
- 默认使用停靠底栏。仍可选悬浮底栏、模糊和液态玻璃；已有显式设置会保留。液态玻璃依赖悬浮底栏和设备支持的模糊，两处共用同一个生效条件。
- 菜单、工具提示、进度指示、下拉刷新、操作按钮和底部弹层使用 Miuix。长文本或代码编辑器保留 Compose Foundation 实现，沿用 Miuix 视觉；需要严格控制返回键和外部点击的确认框保留平台 `Dialog`，外观使用 Miuix。
- 已移除应用对 Material3 的直接依赖。第三方 `priv-kit` 的授权流程仍使用其内置界面，Material3 通过该库提供，并仅在该页面用局部主题同步配色。现有 Material 矢量图标是图标资源，不提供控件外观。

## 构建及验收

使用 JDK 21 和 Android SDK 37，执行：

```sh
bash ./gradlew :gkd-app:assembleGkdDebug :gkd-app:testGkdDebugUnitTest :gkd-selector:jvmTest :gkd-db:jvmTest
```

真机验收建议：

1. 浅色、深色、动态配色和大字号下检查首页四个标签、设置分组、悬浮与停靠底栏；检查点击、横滑、双击回顶和预测式返回。
2. 在应用与订阅列表测试下拉刷新及搜索动作，检查列表在折叠标题、手势导航条和三键导航条下可滚动到底。
3. 分别测试规则、订阅、快照的底部弹层：内容拖动、返回、点外关闭、快速重开、无数据与加载状态。
4. 检查规则编辑器长文本、JSON5 高亮、软键盘退出，以及表单无效状态、确认、取消和放弃草稿；用 TalkBack 确认按钮单次可操作、菜单锚点和统计入口可读。
5. 在 Android 版本和形态不同的设备上验证模糊降级。授权页仅验证配色、导航，除非准备执行权限流程，不要实际开启授权。
