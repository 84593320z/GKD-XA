# Miuix 统一改造：复盘与验收边界

## 本轮范围

在首轮提交 `1f0b7f2` 基础上继续，不改变 34 个导航目的地。逐组审阅首页、设置/关于/工作模式、AI 配置、应用列表、订阅/分类/规则、快照/节点/预览、三类日志、异常报告、通用弹层和第三方授权页。

## 复盘中发现并修复

- 两套开关、设置行、菜单辅助函数的视觉与状态行为不同：统一到底层实现，保留显式自定义行点击；测试开关中心/扩展触区只触发一次。
- 禁用行仍可调用默认动作、可交互子节点重复暴露：统一禁用颜色、单一读屏动作与键盘焦点策略。
- 列表末项被 FAB/导航栏遮挡、粘性标题吸到顶栏后面：修正实际页面的布局和安全内边距，不全局改变业务列表顺序。
- 窄屏日志导出范围、AI 模型操作、请求头等横向挤压：改为可换行/可滚动布局；大字号保持操作可达。
- 快照节点页在短窗口固定控件占尽空间：紧凑布局改为单一可滚动工作区；图像无效时不启用坐标命中，仍保留节点选择。
- 日志分页失败被当成空数据或结束：显示错误和显式重试，不自动触发循环请求。
- 文案帮助关闭编辑器导致草稿丢失：保留编辑器状态，帮助作为高优先级弹层显示。
- 「后台隐藏」确认取消仍写设置：现在明确检查确认结果。
- 复制按钮及编辑计数遮挡文本、标题辅助函数漏传 modifier、系统应用徽标忽略指定颜色：分别预留空间、透传布局与修正颜色继承。
- 授权页仅换配色仍割裂：引入固定版本本地 Miuix UI 层；真实权限宿主和后台文件受冻结校验保护。
- 配对在键盘/分屏短高度下无法滚到按钮、锁定模式仍宣告可点击、两行 snackbar 截断恢复说明：分别引入紧凑全内容滚动、逐项禁用语义和完整可滚动错误说明。
- 原生截图检查发现页面/卡片色阶与宿主倒置：统一为页面 `surface`、卡片 `surfaceContainer`、弹窗 `background`。
- 中文标题/加载/确认文案中的省略号、冒号、问号、括号统一；不修改选择器、URL、模板变量和协议字段。

## 静态分析追加修复

完整 Lint 首轮发现 3 项错误：残留动态背景缺少可识别的 API 33 分支、返回转场直接读取 StateFlow、旧特权文件缩进误导。已分别加入显式版本降级、生命周期订阅和纯缩进修正。特权文件修正前后去除空白的 token 序列一致，不改变授权逻辑。未使用 Lint baseline 或关闭错误检查。

## 验证证据

最终构建后附录由本地验收脚本记录。各门禁的意义分别是：

- Python 架构门禁：防止 Material 控件或旧授权 UI 依赖回流，不能证明绘制正确。
- 授权源码审计：比对冻结后端哈希、权限宿主的展示层以外代码及动作引用，不能代替实际授权测试。
- 原有单元测试：覆盖既有数据/规则/迁移等回归。
- 新增 Robolectric Compose 测试：单次点击、禁用、自定义点击、48dp 触区、输入、错误、长弹窗/列表、窄屏/深色/大字号和纯内存授权预览。
- Native graphics PNG：真实 CPU/Skia 离屏绘制共享控件、授权模拟页和弹窗；不是手机截图，不是所有业务页面的 golden 断言。
- Debug 与 Release/R8：分别验证开发及压缩/资源收缩路径；本地 Release 不使用仓库私钥，不是可覆盖正式版的官方签名发布。

## 未验证项目与限制

手机锁屏后停止 GUI 验收，未解锁、未修改系统开关、未触发 Root/ADB 配对授权，也未覆盖安装正在使用的应用。未将离屏测试冒充真实设备的手势、输入法、转场、后台保活或授权流程验收。

剩余人工验收：不同 Android/厂商、系统字体/TalkBack、真实输入法、极端分屏、进程重建、已配置订阅/大量快照数据、外部服务/权限结果，以及 GPU 毛玻璃/液态玻璃。系统窗口和外部应用不属于本软件的自绘范围。
